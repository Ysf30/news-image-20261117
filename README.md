A dense one-page newspaper front page summing up the world's news of Tuesday 17 November 2026: 31 stories from Ukraine's Kerch Bridge strike to the measles milestone, plus a world map marking where the news happened and the day in figures. Every headline is rendered as crisp text so the image reads on its own; the lead illustration (a broken suspension bridge) and the map are drawn programmatically with PIL.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
